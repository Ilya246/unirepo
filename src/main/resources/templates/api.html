User Management (Admin Only)

GET /users

Get all users

GET /users/user?id={id}
GET /users/self

Get own user ID

POST /users

Create a new user (Admin only)

POST /users/register?username={u}&password={p}

Register a new normal user

PUT /users?id={id}

Update user information

DELETE /users?id={id}

Delete a user

Function Management (Admin Only)

GET /functions

Get all functions or specific function by ID

GET /functions/composite

Get composite data by ID

GET /functions/calculate?id={id}&x={x}

Calculate function value at point x

POST /functions/math

Create a math function

POST /functions/tabulated

Create a tabulated function

POST /functions/pure-tabulated

Create a pure tabulated function

POST /functions/composite

Create a composite function

Owned Functions (User-specific)

GET /owned-functions?id={id}

Get a specific owned function

GET /owned-functions/user

Get all functions owned by user

GET /owned-functions/composite?id={id}

Get the composite function data of an owned function

POST /owned-functions/math

Create a user-owned math function

POST /owned-functions/tabulated

Create a user-owned tabulated function

POST /owned-functions/pure-tabulated

Create a user-owned pure tabulated function

POST /owned-functions/composite

Create a user-owned composite function

POST /owned-functions/own?id={id}&name={name}

Assign ownership of a function to a user (Admin only)

PUT /owned-functions?id={id}&name={name}

Update owned function name

DELETE /owned-functions?id={id}

Delete owned function

Points Management (Admin Only)

GET /points?id={id}

Get all points for a function

POST /points?id={id}&x={x}&y={y}

Add a point to a function

PUT /points?id={id}&x={x}&y={y}

Update a point in a function

DELETE /points?id={id}&x={x}

Delete a point from a function
